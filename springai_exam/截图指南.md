## 一、准备工作（做之前先确认这 3 条）

**1. 确认 8080 端口没被占。**
作业二的服务跑在 **8080**（注意和校园帮的后端 8088、管理端 3000 不是一回事）。
之前命令行起过一个实例占着 8080，如果你要在 IDEA 里运行，先把它关掉，否则会报
`Port 8080 was already in use`。

**2. ✅ API Key 的环境变量已经设好了。**
`application.yaml` 里写的是 `api-key: ${DEEPSEEK_API_KEY:sk-replace-with-your-own-key}`。
`DEEPSEEK_API_KEY` 原本只在命令行里有效、没进 Windows 环境变量，从开始菜单启动的 IDEA 读不到，
直接运行会退回到占位 key、接口全部鉴权失败。

**现在已经把它写进「当前用户」的环境变量（HKCU\Environment）了**，所以 IDEA、cmd、PowerShell
都能读到，这也正符合作业里「API Key 从环境变量读取」的要求。

⚠️ **但必须先把 IDEA 完全退出再重新打开**（不是只关窗口，是 File → Exit 或者右键任务栏图标退出），
它才会拿到新的环境变量。要是还不行，注销一次或重启电脑，一定生效。

（万一以后想撤销：系统属性 → 高级 → 环境变量，在"用户变量"里删掉这一条就行。）

**3. 确认服务是活的。**
浏览器打开 <http://localhost:8080/exam/chat?question=你好>，能看到一段回答就 OK。

## 三、几个需要特别说明的

### ① 跨域（第 10 张）—— 地址栏直接访问是看不出跨域的

同一个页面请求自己不算跨域，浏览器和服务端都不会加跨域响应头。要造一个**真跨域**请求，
不用额外启前端项目：

1. 浏览器先打开 <http://localhost:8080/exam/chat?question=你好> 当跳板页；
2. 按 `F12` → Console，粘贴这行回车：

   ```js
   fetch('http://127.0.0.1:8080/exam/chat?question=跨域测试',{headers:{'X-Test':'1'}})
     .then(r=>r.text()).then(t=>console.log('跨域成功：',t))
   ```

   （`localhost` 和 `127.0.0.1` 在浏览器眼里是两个不同的域，所以这是真跨域；
   带上 `X-Test` 是为了让浏览器先发一条 OPTIONS 预检请求。）
3. 截图 Network 面板里新出现的两条请求（OPTIONS 预检 + GET），点开 Headers，
   要能看到 `access-control-allow-origin: http://localhost:8080`、
   `access-control-allow-methods: GET,POST,PUT,DELETE,OPTIONS`、`access-control-max-age: 3600`。

**这三项服务端都会正常返回，Console 不会报 CORS 错误**（已实测过）。

### ② debug 日志（第 14 张）

1. 先在浏览器访问一次 <http://localhost:8080/exam/chat?question=你好>，让控制台产生日志；
2. 回 IDEA 的 Run 控制台按 `Ctrl+F` 搜 `SimpleLoggerAdvisor` 定位，
   截**一条请求 + 一条响应**，时间戳要露出来（能看出中间隔了好几秒）；
3. 再访问 <http://localhost:8080/exam/chat?question=帮我代写一篇论文>，
   回控制台截这两条 —— 它们的时间戳**只差几毫秒**。
   和上面隔好几秒的一对比，就能证明这次压根没请求大模型。

### ③ 流式效果（第 8 张）—— 关键是「截的时机」

地址栏打开 `/exam/stream?question=图书馆几点开门` 之后，**趁回答还在一个字一个字往外冒的时候按截图键**，
图里要同时有「只出来一半的文字」+「标签页还在转圈 / 状态栏还在加载」。
等它全出完再截，就和一次性返回没区别了。

更严谨的做法：`F12` → Network → 点那条 stream 请求 → Response，能看到内容是一段一段添上去的。

### ④ 改 txt 验证外部化（第 11 张）

1. IDEA 打开 `resources/prompt/exam_prompt.txt`，把第 5 条规则结尾的
   「以上回答希望对你有帮助！」改成别的句子，**不要动任何 Java 代码**；
2. 重启项目，浏览器再访问 <http://localhost:8080/exam/chat?question=你好>；
3. 截图回答的最后一句 —— 已经变成你刚改的新句子了。
4. ⚠️ 截完记得把 txt 改回原样。

### ⑤ 挂载前后对比（第 17、18 张）

1. IDEA 打开 `config/AiConfig.java`，把 `defaultAdvisors(...)` 里的
   `new RewritePromptAdvisor()` 这一行用 `//` 注释掉；
   ⚠️ 它原来是最后一项，注释掉之后要把**上一行末尾的逗号删掉** ——
   Java 的方法参数列表不允许尾逗号，不改会编译报错；
2. 重启项目，浏览器访问 <http://localhost:8080/exam/chat?question=什么是多态>，截图（第 17 张）；
3. 把注释取消、逗号加回去，重启项目，同一个问题再访问一次，截图（第 18 张）；
4. 两张放一起：前一张是模型的自由发挥，后一张第一句是被改写成加粗的一句话结论、
   后面严格按 `1. 2. 3.` 分点展开。

## 四、截图注意

- 网址栏尽量一起截进去，能证明是真实访问；
- `/exam/chat`、`/exam/stream`、`/exam/template` 返回的是**纯字符串**，
  浏览器按 HTML 渲染会把换行压掉、Markdown 的 `**` 原样显示。
  想看带换行的原始返回：`F12` → Network → 点那条请求 → **Response** 标签（还能顺便截到状态码和耗时）。
- 同一个问题**别截图两张完全一样的** —— 比如 5.5 的挂载前后，格式差别要能一眼看出来。
