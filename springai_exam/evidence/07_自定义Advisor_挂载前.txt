**多态**是面向对象编程的三大核心特性之一（另外两个是封装和继承）。简单来说，多态的意思是：

> **同一个接口，不同的表现方式。**

或者说：**父类的引用可以指向子类的对象，调用同一个方法时，会根据实际的对象类型执行不同的行为。**

---

## 一、生活中的类比

假设你有一个“遥控器”按钮叫 `play()`：

- 按下去，如果是**手机**，它播放音乐；
- 按下去，如果是**电视**，它播放视频；
- 按下去，如果是**游戏机**，它启动游戏。

你不需要知道具体是什么设备，只要按 `play()`，各个设备会用自己的方式响应。这就是多态。

---

## 二、代码示例（Java）

```java
class Animal {
    void sound() {
        System.out.println("动物发出声音");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("汪汪汪");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("喵喵喵");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a1 = new Dog();  // 父类引用指向子类对象
        Animal a2 = new Cat();

        a1.sound();  // 输出：汪汪汪
        a2.sound();  // 输出：喵喵喵
    }
}
```

关键点：变量 `a1` 的类型是 `Animal`，但实际执行的是 `Dog` 的 `sound()` 方法。**具体调用哪个方法，在运行时才决定。**

---

## 三、多态的三个必要条件

1. **继承**（或实现接口）：子类继承父类。
2. **方法重写（Override）**：子类重新定义父类的方法。
3. **父类引用指向子类对象**：`Animal a = new Dog();`

---

## 四、多态的分类

| 类型 | 说明 | 例子 |
|------|------|------|
| **编译时多态** | 方法重载（Overload），编译期就确定调用哪个方法 | `add(int, int)` 和 `add(double, double)` |
| **运行时多态** | 方法重写（Override），运行时才确定 | 上面的 Dog/Cat 例子 |

通常说的“多态”主要指**运行时多态**。

---

## 五、多态的好处

1. **可扩展性**：新增子类不需要修改原有代码。比如再加一个 `Bird`，调用方代码完全不用改。
2. **解耦**：调用方只依赖父类/接口，不依赖具体实现。
3. **代码复用**：可以写通用的方法处理所有子类。

```java
void makeSound(Animal a) {   // 参数是父类
    a.sound();
}

makeSound(new Dog());  // 汪汪汪
makeSound(new Cat());  // 喵喵喵
makeSound(new Bird()); // 叽叽喳喳（未来新增也不用改这里）
```

---

## 六、注意事项

- 通过父类引用**只能调用父类中定义的方法**，不能调用子类特有的方法。
- 想调用子类特有方法，需要**向下转型**：`((Dog) a).fetch();`
- 静态方法、私有方法、构造方法**不参与多态**。

---

## 七、一句话总结

**多态 = 一个接口，多种实现；编译看左边（父类），运行看右边（子类）。**
